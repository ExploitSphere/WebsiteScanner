# WebsiteScanner 🔍

A simple and user-friendly website scanner built using **HTML, CSS, JavaScript, Python, and Flask**.

WebsiteScanner provides useful information about a target website and performs basic security-related checks.

## 🚀 Features

- Website information scanning
- IP address lookup
- DNS information
- HTTP/HTTPS status check
- Server information
- Response time
- Port scanning
- Open port detection
- Basic security risk information
- Simple and clean web interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Security / Networking
- Socket
- DNS lookup
- Port scanning
- HTTP requests
