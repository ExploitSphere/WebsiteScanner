# 🔍 WebsiteScanner

A web-based website scanner built with **HTML, CSS, JavaScript, Python, and Flask** for website information gathering and basic security analysis.

🌐 **Live Demo:** https://websitescanner-7eqc.onrender.com

---

## ✨ Features

### 🌐 Website Scanner

- Website reachability check
- HTTP status code
- Response time
- HTTP/HTTPS detection
- Domain information
- IP address lookup
- Server information
- Security score
- Security headers analysis
- Missing security headers detection
- Redirect detection
- Robots.txt detection
- Sitemap.xml detection
- WHOIS information
- SSL certificate information
- Cookie security analysis

### 🔌 Port Scanner

- Domain-based port scanning
- Open port detection
- Service identification
- Port status
- Basic risk analysis
- Scan time
- Number of ports checked

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/ExploitSphere/WebsiteScanner.git
```

### 2. Open the project

```bash
cd WebsiteScanner
```

### 3. Install backend dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 4. Start the Flask backend

```bash
python app.py
```

The backend will start locally on:

```text
http://127.0.0.1:5000
```

### 5. Open the frontend

Open:

```text
frontend/index.html
```

in your browser.
